# FORMA — Responsive Landing Page

A landing page for a fictional digital studio, built with HTML, CSS, and JavaScript for my Full Stack Internship task

## About

The website includes a home section, services, two concept projects, testimonials, and a contact form

I focused on making the layout work across different screen sizes and adding interactions to the navigation, buttons, and cards

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile menu and smooth scrolling
- Project filters and image hover effects
- Expandable service cards
- A 3D flip card
- Testimonial slider
- Button hover and click effects
- Form validation and project brief download
- Back-to-top button
- Keyboard navigation and reduced-motion support

## Project files

- `index.html` — page structure and content
- `css/style.css` — styling, backgrounds, and responsive layouts
- `js/script.js` — interactive features
- `images/` — project photos
- `favicon.svg` — browser tab icon
- `IMAGE-CREDITS.md` — photo sources
- `COURSE-NOTES.md` — study notes in Arabic

## Run the project

Download the files and open `index.html` in your browser, or use Live Server in VS Code

No installation or build command is needed

## Images

The photos are saved in the `images` folder and added through CSS using `background-image`

They come from the same photography series to keep the colours and overall style consistent

Sources are listed in `IMAGE-CREDITS.md`

## Contact form

The form checks the entered information and downloads a text file containing the project brief

It does not send emails or store data online

## Demo content

The studio, projects, and testimonials are fictional

The photos are used for illustration, the email address is a placeholder, and the social links lead to the platforms’ homepages

## GitHub Pages

1. Create a public repository named `landing-page-project`
2. Upload the project files, including the `images` folder
3. Go to Settings → Pages
4. Select the `main` branch and the root folder
5. Save and wait for the website link to appear
